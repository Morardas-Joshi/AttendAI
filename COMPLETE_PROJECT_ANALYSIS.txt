==========================================================================
                COMPLETE PROJECT ANALYSIS: SMART ATTENDANCE SYSTEM
==========================================================================

HIGH-LEVEL SUMMARY:
This project is an automated attendance system that leverages AI-based Face Recognition 
and GPS-based Geofencing. It is built using the Laravel framework for the web backend, 
MySQL for data storage, and a Python FastAPI service for the AI processing.

SYSTEM ARCHITECTURE:
- The Web Interface (Laravel) handles user authentication, session management, 
  and reporting.
- The AI Engine (Python) provides specialized endpoints for face registration, 
  recognition, and liveness detection.
- The Database (MySQL) stores user details, student face encodings, attendance 
  sessions, and final attendance logs.

HOW THE FILES CONNECT:
1. Routing (routes/web.php) maps URLs to Controller methods.
2. Controllers (app/Http/Controllers) handle the business logic and call AI 
   endpoints using HTTP requests.
3. Models (app/Models) interact with the database tables.
4. AI Service (ai-service/main.py) is called by Controllers to verify images.
5. Views (resources/views) provide the user interface for students, faculty, 
   and admins.
